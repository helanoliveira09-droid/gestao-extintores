🔴 Guia de Inspeção de Extintor

O que Verificar:

  • ✓ Aparência: Procure por danos visíveis, enferrujamento, amassados ou deformações.
  • ✓ Manômetro: Verifique se a agulha está na zona verde. Agulha vermelha = pressão inadequada.
  • ✓ Lacre e Pino: O lacre deve estar intacto. Se foi quebrado, o extintor foi usado.
  • ✓ Acessibilidade: O extintor deve estar visível, acessível e sem obstáculos.
  • ✓ Etiquetas: Verifique o adesivo de inspeção com data da última revisão.

Tipos de Extintor:

  • 🔴 AP (Água Pressurizada): Para incêndios classe A (madeira, papel)
  • 🟠 BC (Pó Químico Seco): Para incêndios classe B e C (líquidos, gases)
  • ⚪ BC CO2 (Dióxido de Carbono): Para incêndios classe B e C, ideal para ambientes com equipamentos elétricos e eletrônicos, não deixa resíduo
  • 🟡 ABC (Pó Polivalente): Para incêndios classes A, B e C
